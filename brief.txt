Brief schema (v1)
=================

Briefs are AI-generated snapshots woven from stitches (and past briefs) on
`brief me`. Brand voice: stitches make the garment; briefs are what you put on.

Table: briefs
-------------

| Column              | Type        | Required | Notes                              |
|---------------------|-------------|----------|------------------------------------|
| id                  | TEXT (UUID) | yes      | Primary key                        |
| user_id             | TEXT        | yes      | Owner scope                        |
| kind                | TEXT        | yes      | morning, on_demand, travel         |
| generated_at        | TIMESTAMPTZ | yes      | When this brief was synthesized    |
| greeting            | TEXT        | no       | Opening line                       |
| headline            | TEXT        | no       | Summary title                      |
| bullets             | JSONB       | yes      | Array of { text, priority? }       |
| related_stitch_ids  | TEXT[]      | yes      | Stitches cited in this brief       |
| created_at          | TIMESTAMPTZ | yes      | Row created                        |

API shape (camelCase JSON)
--------------------------

{
  "schemaVersion": 1,
  "id": "uuid",
  "userId": "string",
  "kind": "on_demand",
  "generatedAt": "ISO-8601",
  "greeting": "string",
  "headline": "string",
  "bullets": [
    { "text": "string", "priority": 1 }
  ],
  "relatedStitchIds": ["uuid"],
  "createdAt": "ISO-8601"
}

Source of truth
---------------

- Zod schema: shared/src/brief.ts  (@briefs/shared)
- SQL migration: db/migrations/003_briefs.sql
- API: @briefs/system
  - GET /api/v1/briefs
  - GET /api/v1/briefs/:id
  - POST /api/v1/brief/generate
