# Plugin

Assistant integration for Holmplanet Briefs — Codex/Cursor plugin manifests and skills.

The Brief skill documents the connector-agnostic calendar-to-morning-brief workflow. Item examples use the v4 field names (`name`, `kind`, `lifecycle`, `occurredAt`).

Not an npm workspace. Point your assistant at `client/plugin/` for local development or adapt the
MCP URL for a self-hosted deployment.

Update `plugin.json` and `.mcp.json` when the system API surface changes.
