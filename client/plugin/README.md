# Plugin

Assistant integration for Holmplanet Briefs — Codex/Cursor plugin manifests and skills.

**Note:** `skills/brief/SKILL.md` still documents legacy MCP brief tools; item examples use the v4 field names (`name`, `kind`, `lifecycle`, `occurredAt`).

Not an npm workspace. Point your assistant at `client/plugin/` or install from this path when publishing.

Update `plugin.json` and `.mcp.json` when the system API surface changes.
