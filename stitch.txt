Stitch schema (v1)
==================

Stitches are atomic items users capture. AI weaves them into **briefs** (generated
snapshots). Brand voice: stitches make the garment; briefs are what you put on.

Table: stitch_nodes
-------------------

| Column        | Type        | Required | Notes                          |
|---------------|-------------|----------|--------------------------------|
| id            | TEXT (UUID) | yes      | Primary key                    |
| user_id       | TEXT        | yes      | Owner scope                    |
| label         | TEXT        | yes      | Human-readable title           |
| status        | TEXT        | yes      | open, in_progress, done, cancelled |
| due_at        | TIMESTAMPTZ | no       | Due datetime                   |
| scheduled_at  | TIMESTAMPTZ | no       | Planned start                  |
| completed_at  | TIMESTAMPTZ | no       | Set when status becomes done   |
| priority      | TEXT        | no       | low, normal, high, urgent      |
| description   | TEXT        | no       | Longer body text               |
| created_at    | TIMESTAMPTZ | yes      | Row created                    |
| updated_at    | TIMESTAMPTZ | yes      | Last mutation                  |

Source of truth
---------------

- SQL migration: db/migrations/001_stitch_nodes.sql
- API: @briefs/system — GET/POST/PATCH /api/v1/stitches

Monorepo layout
